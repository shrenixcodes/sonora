# Security

Please do not post credentials, personal information, or exploitable details in a public issue.

Use GitHub's private vulnerability reporting on the [repository security page](https://github.com/shrenixcodes/sonora/security) if it is enabled. If it is unavailable, open an issue with no sensitive details and ask the maintainers for a private reporting route.

A useful private report includes the affected version or commit, Windows and WebView2 versions, reproducible steps, impact, and any relevant logs with tokens, account identifiers, and personal data removed. Please allow maintainers time to investigate before public disclosure. There is no published response-time guarantee.

Sonora uses a separate WebView2 profile for YouTube Music. Treat that profile and exported files as private; do not attach them to reports or commits. See [the contributing guide](CONTRIBUTING.md) for routine bug reports.
