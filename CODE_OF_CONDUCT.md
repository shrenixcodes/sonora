# Code of conduct

Sonora's issue tracker, pull requests, and project discussions should be welcoming and useful to everyone.

- Be respectful and constructive. Critique ideas and code without attacking people.
- Do not harass, threaten, discriminate, or publish another person's private information.
- Respect boundaries and differing levels of experience. Help people understand feedback.
- Maintainers may remove inappropriate content or restrict participation when needed to protect the community.

To report a conduct concern, contact a project maintainer privately if a private channel is available. If you cannot find one, open an issue asking for a private contact route without including sensitive details. Do not post private information in a public report.
