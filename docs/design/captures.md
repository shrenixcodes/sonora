# Capturing Sonora visuals

Use real captures from the current desktop build. Do not use generated mockups, placeholder images, or captures from an older version as evidence of the current interface. Remove account names, email addresses, personal playlists, private listening history, notifications, and other private information before sharing a capture. Use artwork and audio you have permission to publish.

## Capture set

1. Build and run the current desktop app on Windows. Open Now Playing and choose content that is safe to share.
2. In Settings, select Aurora, Fluid, Glow, Cinematic, and Minimal in turn. Capture the same app view and window size for each mode. The visualizer uses artwork-derived colors, so record which track or artwork was used.
3. Capture a matched dark/light pair at the same size and view. Check legibility, focus, and floating window edges before exporting.
4. Record a short muted visualizer clip, then export an optimized GIF or video. Do not claim the clip represents a different mode or release.
5. Place approved captures in `docs/images/` and link them from the README with descriptive alt text. Verify paths on GitHub and check the file sizes before committing.

The approved v0.7.20 desktop capture set lives in `docs/images/` (launch splash GIF, taskbar restore GIF, floating `Fluid` hero GIF, all 5 Now Playing visualizer screenshots, plus matched Charcoal Dark and Bone Light Search screenshots). The palette and mood board graphics in this folder document color tokens separately.
